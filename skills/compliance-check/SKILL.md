# 募集文書のコンプライアンスチェック

渡された文面を確認し、問題になりやすい表現と言い換え案を示す手順です。
最終判断は社内のコンプライアンス部門が行う前提で、一次チェックとして使います。

## 確認する観点

1. **断定的判断の提供**: 「必ず」「確実に」「絶対に」「損をしない」など、将来の不確実な事柄を断定する表現。
2. **税務の断定**: 「節税になります」「税負担が軽減されます」と言い切る表現。税制は個別事情と改正により変わるため、「税務の取扱いは税理士等にご確認ください」と添える。
3. **他社との不当な比較**: 他社商品を名指しで劣っているとする表現、根拠のない「業界最安」「No.1」などの表現。
4. **重要事項の説明漏れ**: 保障されない場合（免責事由）、解約返戻金がないこと、保険料が変動することなどに触れていない記述。

## 出力フォーマット

```
### チェック結果: 問題あり / 問題なし

| 該当箇所 | 観点 | 理由 | 言い換え案 |
|---|---|---|---|

### 補足
```

## 注意事項

- 問題がない場合も「問題なし」と明記する。
- 本チェックは法的判断ではないことを最後に一文添える。
