# 提案骨子の作成

顧客企業への提案の骨子を、社内データに基づいて作る手順です。

## 手順

1. 対象企業と、指定があれば提案したい商品を特定する。
2. 面談メモ検索ツールで、先方が話していた課題や関心事を集める。
3. 営業分析ツールで、既契約・進行中の商談・従業員数・財務の推移を確認する。
4. 商品資料検索ツールで、提案商品の特長と引受条件を確認する。
5. 以下のフォーマットで骨子を出力する。

## 出力フォーマット

```
## 〇〇社 ご提案骨子

### 1. 先方の課題（面談で伺った内容）
### 2. ご提案内容（商品名と提案理由）
### 3. 根拠となるデータ（既契約・従業員数・財務・採用の数値）
### 4. 導入スケジュール案
### 5. 次のアクション（社内・先方それぞれ）
```

## 注意事項

- 根拠には、使ったデータの出典（面談メモの日付、商品資料のファイル名など）を添える。
- 他社商品を名指しで比較・批判しない。
- 「必ず」「確実に」などの断定表現は使わない。
